## ブラウザ検証

```powershell
node scripts/verify_interview_demo.cjs
```

検証用PlaywrightとChromiumが必要です。デモの起動には不要です。
未導入なら、リポジトリー内で次を実行します（ネット接続が必要）。

```powershell
npm install --prefix .demo-tools --no-save playwright
.\.demo-tools\node_modules\.bin\playwright.cmd install chromium
node scripts/verify_interview_demo.cjs
```

検証スクリプトは一時ポートで自分のサーバーを起動し、終了時に停止します。
外部へのブラウザ通信をブロックし、外部リクエスト0件、JavaScriptエラー0件を確認しました。
再生・一時停止・再開・1本送り・スライダー・ケース切り替え・リロード・JSON取得が成功しました。
横幅320、390、768、1440pxでページおよび主要テキストのはみ出しがないことを確認しました。
価格と資産のCanvasは描画ピクセルを確認し、デスクトップ・モバイルの画像も目視しました。
スクリーンショットと機械可読レポートは `.demo-artifacts/` に生成し、Gitには含めません。
